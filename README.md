# CONVINCE-ultrafiltration-rate
Comparison of ultrafiltration rate (both over time and its association with all-cause mortality) in high-volume hemodiafiltration versus high-flux hemodialysis 

NOTE
We start this script with a dataframe formatted to long format. This is the same script as for the post-hoc analysis of nutrition. Similarly, the imputation of missing values and the weighting procedure are the same as for the nutritional analyses. To see these scripts, I refer to the repository of that project: https://github.com/SRoos2025/CONVINCE-nutrition (script 0-3).
